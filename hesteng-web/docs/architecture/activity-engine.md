# HESTENG Competition Engine

## Formål

Competition Engine er den centrale motor, som styrer turneringer.

## Motorer

RankingEngine
- Opretter seed-rækkefølge.

SeedEngine
- Bestemmer hvilke puljer en seed må komme i.

DrawEngine
- Gennemfører lodtrækningen.

ScheduleEngine
- Opretter kampprogram.

KnockoutEngine
- Opretter slutspil.

StatisticsEngine
- Beregner statistik.
